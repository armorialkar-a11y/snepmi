SNEPMI AGENCY — повторная проверка и превью

Итог: production-сборка и 21 модульный тест прошли. В проверенных локальных
пользовательских сценариях ошибок выполнения JavaScript не обнаружено.
Это не гарантия отсутствия всех возможных ошибок и не полный аудит безопасности.

Проверено в Chromium на ширинах 320, 390, 768, 1440:
- Главная → блок блогеров → полный каталог → главная.
- Все 38 карточек и их фотографии.
- Поиск, фильтры площадок и тематик, сброс фильтров, пустой результат.
- Единые темы «лайфстайл» и «липсинги».
- Полное отсутствие блока «Условия рекламы» в карточках: никаких цен,
  гарантий или порогов просмотров. Отдельные ограничения сохранены.
- Дополнительно раскрыты и проверены Регина, РИАНКА, Полина.
- Сердечки, счётчик, удаление выбранного автора, исчезновение панели после
  снятия выбора, сохранение выбора при смене фильтров.
- Telegram-ссылка к @nesssvt с черновиком и именами выбранных авторов.
- Форма: ошибки валидации и успешный сценарий с локальным тестовым ответом.
  Использовалась настоящая схема валидации проекта, но не рабочая база/бот.
- Экран отказа в доступе к админке на имитированном ответе 401.
- Пустой каталог, ошибка API и повторная загрузка.
- Отсутствие горизонтальной прокрутки на проверенных размерах.

Отдельно проверены при обычной анимации на 390 и 1440:
- Куклы плавно растут и поднимаются вверх поверх логотипа по исходной
  геометрии HeroScroll. Проверены начало, середина, конец и обратная прокрутка.
  Волосы и обувь остаются внутри сцены; перекрытие логотипа намеренное.
- Проверены размеры 320×900, 390×600, 390×1000, 768×1000 и 1440×1000.
- События Telegram viewportChanged: нестабильные кадры игнорируются.
- Открытие/закрытие конверта и быстрое изменение направления анимации.
- Настройка «Уменьшение движения».

Дополнительно исправлено при повторной проверке:
1. LeadDialog.jsx: при отсутствии настройки контакта форма использует
   @nesssvt, а не дополнительный контакт @advmiu.
2. telegram.js: используется реальный метод BackButton.offClick при очистке
   обработчика кнопки «Назад».
3. App.jsx + launch-route.js + server/bot.js: обычный запуск и старый параметр
   startapp=catalog ведут на главную; новые кнопки бота используют startapp=home.
   Прямой startapp=bloggers по-прежнему открывает каталог, admin — админку,
   form/lead — форму на главной. Все шесть вариантов проверены локально.
   Сам бот и его настройки в Telegram НЕ менялись: это произойдёт после деплоя
   при штатном запуске приложения, если бот и MINI_APP_ORIGIN настроены.

Автономное интерактивное превью SNEPMI-preview-dolls-up.html:
- Открывается с главной. Каталог доступен через «Смотреть всех блогеров».
- Фотографии, стили и JavaScript встроены в один HTML.
- Работают фильтры, сердечки, панель выбора, раскрытие карточек и конверт.
- Для первого открытия не требуется сервер или интернет.
- Реальные заявки и доступ в админку отключены. Нажатие «Отправить заявку»
  показывает, что это предпросмотр; запрос не уходит на рабочий сервер.
- Внешние ссылки могут открыть настоящий Telegram/профиль по нажатию.
  Telegram-текст — черновик, его отправляет только сам пользователь.
- Проверено открытие самого HTML с диска на 390 и 1440: нет внешних сетевых
  запросов при просмотре и нет ошибок JavaScript в проверенных сценариях.
- Этот HTML — только превью, НЕ замена React/Express-проекту на Render.

Предупреждения зависимостей (npm audit --omit=dev):
- Всего 3: 2 high, 1 moderate, critical нет.
- Vite 5.4.21 — high, несколько уведомлений, преимущественно о dev-сервере
  и инструментах разработки; esbuild 0.21.5 — moderate, dev-сервер.
- Zod 3.25.76 — high: потребление памяти при валидации слишком больших коллекций.
- Они НЕ исправлены в этом пакете. npm предлагает обновления основных версий
  Vite/Zod, поэтому автоматический npm audit fix --force не запускался.
- Нужна отдельная проверяемая миграция зависимостей. Не публикуйте Vite dev-
  server в интернете; рабочий старт Render оставьте node server/index.js.
- Эти предупреждения не равны найденной поломке интерфейса, но требуют
  отдельного внимания до вывода о безопасности проекта.

Рабочий сервер, бот, база и GitHub в ходе проверки не менялись.
