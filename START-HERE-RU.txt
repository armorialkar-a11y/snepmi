SNEPMI AGENCY — ИТОГОВЫЙ ПОЛНЫЙ ПРОЕКТ

Это полный исходный проект, НЕ архив отдельных патчей.
Включены все ранее согласованные исправления и последняя плавная анимация
кукол: увеличение и подъём поверх логотипа, мягкая смена направления.
Условия рекламы скрыты целиком; ограничения сохранены отдельно.

ВНУТРИ
- server/, shared/, web/src/, web/public/, data/, tests/: исходники и фото.
- package.json, package-lock.json: зависимости и команды.
- render.yaml: существующий шаблон для НОВОЙ установки, не запускать
  новый Blueprint для обновления действующего сервиса.
- .env.example: пустой шаблон переменных, не настоящие секреты.
- CHECK-REPORT-RU.txt: проверки, ограничения и предупреждения зависимостей.
- В итоговом ZIP есть PREVIEW/ с отдельным HTML-превью и видео.
  Они не входят в ветку GitHub и не нужны серверу Render.
  В превью заявки не отправляются.

ОБНОВЛЕНИЕ СУЩЕСТВУЮЩЕГО ПРИЛОЖЕНИЯ
1. Сохранить предыдущий коммит, проверить актуальный код репозитория
   и сделать резервную копию рабочей PostgreSQL.
2. Сопоставить исходники архива с текущим репозиторием. Если после передачи
   исходного ZIP были другие правки, сохранить их, а не затирать вслепую.
3. Сохранить текущие DATABASE_URL, BOT_TOKEN, ADMIN_USER_IDS, NOTIFY_CHAT_ID,
   MINI_APP_ORIGIN и настройки polling/webhook. Секреты не хранить в GitHub.
4. Использовать СУЩЕСТВУЮЩИЕ сервис и базу в Render. Для заполненной базы
   AUTO_SEED=false; никогда не запускать seed --force при обновлении.
   Для первой установки на пустую базу нужен отдельный обычный seed.
5. Build command: npm ci && npm run build
   Start command: node server/index.js
   Health check: /api/health
   NODE_ENV=production. Не включать AUTH_DISABLED.
6. После обновления проверить главную страницу в Telegram, плавную прокрутку
   кукол вперёд/назад, конверт, каталог, сердечки, черновик @nesssvt, форму
   и админку. Не отправлять тестовые заявки без необходимости.

ПРОВЕРКИ ЛОКАЛЬНО
npm ci
node --test tests/*.test.js
npm run build

Готовый HTML создаётся сборкой в web/dist/index.html. Для Render нужен
весь проект и сервер, не только этот HTML. node_modules и web/dist
в архив не включены: Render устанавливает зависимости и собирает проект.

ВАЖНО
Это сборка из ранее переданного проекта. Рабочий GitHub, Render, бот
и база сейчас не изменялись. Подключение и деплой — следующий отдельный шаг.
Пароли, BOT_TOKEN и другие секреты не отправляйте в чат.
